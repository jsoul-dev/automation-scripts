# Spotify Uninstaller for Windows

[![Download Script](https://img.shields.io/badge/Right--Click_%E2%86%92_Save_Link_As...-blue?style=for-the-badge&logo=download)](https://raw.githubusercontent.com/jsoul-dev/automation-scripts/main/spotify-uninstaller/spotify-uninstaller.bat)

Completely removes Spotify Desktop and Spotify Microsoft Store versions from your system.

## Overview

This script is designed to thoroughly clean your system of any Spotify and Spicetify installations. It removes not just the applications, but also residual files, local application data, and leftover registry entries to ensure a completely clean slate.

## Usage

> [!CAUTION]
> The script completely removes all local data for the Spotify and Spicetify applications. By running it, you acknowledge that you fully understand what you are doing.

**Important:** You **must** run the script as an Administrator for it to successfully remove registry keys and protected files.

1. Right-click on `spotify-uninstaller.bat`.
2. Select **"Run as administrator"**.
3. Follow any on-screen prompts.

## What It Removes

- **[Spicetify](https://spicetify.app/)**
- **Spotify** (Desktop & Microsoft Store versions)
- **Residual Files** remaining from the official Spotify installer
- **Registry Keys and Values** remaining from the official Spotify installer
